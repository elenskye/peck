# 界面

> 用词对照、布局、各处的样子。定值都在 `src/vendor/peck/`（visual-atelier 方案 `peck` 同步来的，不手改）：`DESIGN.md` 是视觉基线，`peck-rules.md` 是外框规则 66 条，`DESIGN-SYSTEM.md` 和 `components/` 是组件怎么写；这里只写结论。

## 布局

三栏，Phase 3 起：

```
┌────────────────────────────────────────────────────────────┐
│ 项目名           模式（CLI / API）                    设置 │  ← 顶栏只有这三样
├──────────────┬──────────────────────────┬──────────────────┤
│ 项目和任务     │ 对话                      │ 右栏：四个页签     │
│              │                          │ CHANGES ONE SHOT │
│ 项目列表       │ 任务的提问、回答、总结      │ FILES   TERM     │
│  └ 最近几次任务 │ 折叠的步骤（点开看输出）    │                  │
│ 点进项目：     │ 停下来问你 / 高危操作卡片   │ 一次开一个，      │
│  任务列表      │                          │ 能展开到宽栏       │
│              │ ┌──────────────────────┐ │                  │
│              │ │ 一句话  谁来干  权限   │ │                  │
│              │ └──────────────────────┘ │                  │
└──────────────┴──────────────────────────┴──────────────────┘
```

- **窗口**：红绿灯在顶栏那一行、PECK 左边（`tauri.conf.json` 的 `trafficLightPosition`，在 Mac 上量过）；按住顶栏的空白、PECK、项目名都能拖窗口。
- **打开 App**：左栏是项目列表，每个项目带最近几次任务；还没项目时是空状态，一个「打开项目文件夹」。
- **左栏**：上面一块 PROJECTS：点项目展开它的任务列表（新的在上，第一行 NEW TASK），别的项目收成一行；再点一下项目名或「全部项目」回到项目列表。在跑的任务有标记。下面一块 LOG：正在看的这个任务的记录（存快照、每一步、做完、撤销）。
- **中栏**：上面是任务内容，下面是发任务的输入框和「谁来干」。跑完的任务末尾是一段总结和验证结果。
- **右栏**：四个页签，见下面「右栏」。
- **设置**：一个面板占宽栏，左边竖排七组：供应商和 Key（含模型）、花费上限、权限、CLI 检测、通知、外观、开发者选项（假 Agent、API 模拟 / 真实、导出调用记录、单次请求——它 v0.6 搬进 ONE SHOT）。
- **额度与花费**：从顶栏设置旁或左栏底部进，一页概览。
- **菜单栏**：一个小图标，有任务在跑时变样（v0.7 起显示在跑的数量）；任务完成、要回答时发 macOS 通知，设置里能关。
- **明暗**：跟随系统。

## 谁来干

发任务时在输入框旁边选，分两组：

| CLI 模式 | API 模式 |
|---|---|
| Muse | 单模型干活（选一个模型、思考强度） |
| Grok | 规划 + 实施（选两个模型） |
| Muse → Grok | |
| Grok → Muse | |
| 勾选「让它调用 API 模型帮忙」 | |

只显示能用的：CLI 检测到才出现，API 只显示配了 Key 的供应商；选了没配 Key 的模型当场弹输入框。单次请求不在这里，挪进了右栏的 ONE SHOT（站主 2026-11-10 定）。

## 权限

发任务时在「谁来干」旁边选，三档，默认 EDIT（站主 2026-11-10 定）：

| | 改文件 | 跑命令 | 装依赖、联网 | 删文件 | 改项目外的（推送也算） |
|---|---|---|---|---|---|
| PLAN（只读：读代码、写计划） | 不改 | 不跑 | — | — | — |
| EDIT（默认） | 不问 | 不问 | 一次批 | 一次批 | 一次批 |
| AUTO（全部放行） | 不问 | 不问 | 不问 | 一次批 | 一次批 |

「一次批」：开始改之前一张卡把这些事一起批，不一条条问；项目外的默认不勾。

## 右栏

顶上一条页签：CHANGES / ONE SHOT / FILES / TERM，一次开一个。切走以后页签上说那边有新东西（改了几个文件、答完了、命令在跑或跑完、终端锁着），从不自己切走正在看的页签。每个模块都能展开到宽栏（中栏和右栏合起来）；展开时任务停下来等你，宽栏顶上一条提示，点 BACK 收回。模块之间只靠「带上」和「跳过去」连，不开新窗口。

- **CHANGES（改动）**：这个任务改了哪些文件，点文件看 Diff；任务前快照；最下面「撤销整个任务」（原地确认一次）。一个任务里发过好几次时，默认看最新一次；中栏每次记录的头上有一个 CHANGES，点了右栏和左栏的 LOG 就换成那一次（快照那一行写着是任务几号），再发一次回到最新。读不出 Diff 时写明原因（比如项目文件夹不在了）。
- **ONE SHOT（边干活边问）**：问一句答一句，不打断任务。
  - 谁来答：左下的选项片弹菜单，CLI 一组（Muse、Grok）、API 一组（配了 Key 的模型）；默认跟顶栏的模式（CLI 模式默认 Muse，API 模式默认「谁来干」里选的模型），换了就记住。没配 Key 时 API 一组只留一行「配 Key」当场填。
  - 能读整个项目，不改文件、不跑命令：CLI 用 PLAN 档跑，API 只给读文件的工具。回答上写读了哪些文件。
  - 任务进度和终端输出它看不到，用 + 带上；带上 FILES 里的文件是「指着它问」。
  - API 答完写这一问花了多少（算进花费上限），CLI 写「订阅额度」。回答只给 COPY 和 TO TASK（放进中栏输入框）。
- **FILES（看文件）**：只看不改。照忽略规则藏起 node_modules 这些并写一句藏了几个；这个任务改过的文件标法和 CHANGES 一样；预览带行号，改过的行左边一条绿，删掉的文件预览删之前的样子。
- **TERM（你的终端）**：开在项目根目录，不经过权限三档，不进模型上下文；Agent 跑的命令在中栏步骤里看。每条命令跑完写退出码和用时，失败那条能带上输出去 ONE SHOT。
  - 模型在跑任务时终端锁着（站主 2026-11-10 定）：从发出到做完，等你批、等你答、撤销的时候都算，PLAN 档也锁。输入行和页签各一把锁；输出照样能看、能带去 ONE SHOT。
  - 发任务前就在跑的命令接着跑，STOP 一直能点；它要是改了项目里的文件，算进这次改动。
  - 做完解锁。之后在终端改的文件不算进这个任务，撤销只动任务改过的文件，确认里写清。

## 样子

方案 `peck` 0.1.0（站主 2026-11-10 批，Design System「[Peck](https://claude.ai/artifact/KpUihg5AHn6cw1ggNTx6s1)」）：**点阵终端 × 深海**。深色是深海底上一层 LED 点阵孔，青 `#00E5FF` 是全屏唯一会发光的颜色；浅色是冷白底，青换成深青 `#007A94`，没有发光。不像 VSCode：不用一层层灰面板 + 满屏等宽字。

- **怎么接**：根元素写 `data-theme="dark"` 或 `"light"`（`src/lib/theme.ts`，跟随系统）；先引 `src/vendor/peck/peck.css`（变量、字体样式类 `t-*`、两个字体），再引 `bundle.css`（组件类名都以 `pk-` 开头，写法照 `components/<组件>/preview.html`）。界面只用 `--color-*` 这些变量和 `pk-` 类名，不抄色值。
- **颜色**：34 个角色，深浅两套。颜色只留给意思：青在发生、绿新增和完成、琥珀等你、红删除和出错；同一时刻只有一个青色主按钮、只有一块模块描彩边。身份色只做 7 像素的色点：Muse 紫、Grok 橙、API 蓝。改色要过 APCA。
- **字**：名字和标题用缝合像素 12（12、18、24 号）；说明和正文用 IBM Plex Sans + 苹方（12.5 号）；代码、路径用 Departure Mono 11（字号不小于 12 的唯一例外）；数字、标签、按钮用 Doto 900，只写英文大写（`[ CHANGES ]`、`SEND`）。
- **形**：没有圆角，全是像素阶梯角（模块 2 级 × 3px，控件 2 级 × 2px）；模块两层，状态靠外层换色；发光只在深色、只给青色；键盘焦点是控件里面一圈青点线。图标 8×8 像素格画成 16，不混别的图标集、不用 emoji。
- **尺寸**：三栏 288 / 自适应 / 336，栏间 16；顶栏高 44；按钮 34、小按钮 26、输入行 30、列表行 23、菜单行 30；间距只用 2、4、6、8、10、12、14、16、18、22、28、30。
- **动效**：一格 50ms，一步一格地跳，时长都是整格。控件状态立刻变；出现、露出、溶掉 4–8 格（calm）；发出、等你、做完、撤销这几个时刻各有一个招牌动作，单次不超过 1 秒；在跑、等待能循环。减弱动态效果时只留最后的样子。
- **图标**：App 图标 J2（像素鸟，深海渐变底板占 7/8），每个尺寸用对应的底稿（16、32 是重画的小鸟，不从 1024 缩）；设置里能换成现在的图标润色版 A3。菜单栏模板图高 18pt，14 格的鸟，在菜单栏里一格 1.5pt（鸟 15×13.5pt，和系统图标差不多大；方案里写的一格 1pt 在刘海屏的菜单栏里偏小，站主 2026-11-11 说要大一点），四个状态：空闲、在跑（三颗点轮流亮）、等你（问号）、在跑 N 个（v0.7 起）。文件在 `src/vendor/peck/marks/`。
