# 界面

> 用词对照、布局、各处的样子。定值都在 `src/vendor/peck/`（visual-atelier 方案 `peck` 同步来的，不手改）：`DESIGN.md` 是视觉基线，`peck-rules.md` 是外框规则，`DESIGN-SYSTEM.md` 和 `components/` 是组件怎么写。行为在 [architecture.md](./architecture.md)。

## 布局

- **顶栏**只有项目名、QUOTA、设置。红绿灯在顶栏那一行、PECK 左边；按住顶栏空白、PECK、项目名都能拖窗口。明暗跟随系统。
- **三栏**：左栏 NOW、PROJECTS、AGENTS；中栏是对话和输入框；右栏六个页签，一次开一个。设置、项目设置、QUOTA 和展开的右栏模块占宽栏（中栏 + 右栏），CLOSE 或 Esc 收回。
- **设置、项目设置是大号页**：模块里面整块放大 1.5 倍（像素字 12→18），从这里弹出的菜单、ⓘ 跟着放大；窗口窄时左边分组变窄。
- **弹层**（下拉、菜单、ⓘ、右键菜单、@ 和 / 列表）：一律用 `src/ui.tsx` 的 `<Float>`。想往哪边弹那边放不下就翻到另一边，两边都不够就压矮在里面滚；左右夹在窗口里。
- **对话的位置**：第一次进一个任务停在最新一轮的开头（最后一条 YOU 顶到上面）；回到看过的任务回到上次的位置（退出重开也记得）；离开后多了新的一轮、或在这里发了下一句，去新的那一轮。
- **全部项目页**（没选项目时）：中栏一块 `[ PROJECTS ]`，列全部项目，每个带最近 5 次任务（标题、状态和时间），多的写「还有 n 个」；头上右边 OPEN FOLDER；有等你的、在跑的，上面出 `[ NOW ]`。这时左栏一整块都是 AGENTS（一直展开，没有收起的三角）。点一个项目或任务就进去。
- **`[ NOW ]`**：跨项目的「待你处理、在跑」，没有、或 PROJECTS 收起时不出现。一行一个任务，顺序：等你批或答（琥珀问号）、停下了没看（红叉）、做完了没看（绿勾）、在跑（闪烁的点）；最多 8 行。打开过或在眼前做完的算看过。
- **PROJECTS**（选了项目以后的左栏）：项目名用像素字 18px；选中的项目列全部任务（新的在上，第一行 NEW TASK），别的项目只带最近一次。头上：文件夹图标打开新项目，右边放大图标回全部项目页，最右是收起的三角；不写项目个数。
  - 右键项目：重命名、项目设置、在访达里显示（文件夹不在了换成「重新找文件夹」）、归档全部任务、移出列表；右键任务：重命名、归档、删除任务（在跑的不能归档、不能删）。归档全部、移出和删除都点两下，第二下写后果；重命名就地变输入框。全部项目页里一样。
  - 拖动换顺序，放下的位置一条青线。
  - 文件夹不在了：那一行琥珀感叹号和「文件夹不在了」，中栏是 MISSING：FIND FOLDER 或 REMOVE。
- PROJECTS、AGENTS 都能收起（模块头最右的小三角），收起的只剩模块头和一行要紧的（当前项目 / 现在是谁），另一块占满；记在设置里。
- **归档**：任务收起来不在左栏列，记录、快照都留着。设置 → ARCHIVE 按项目分组列出，每行 OPEN / RESTORE / DELETE；OPEN 在中栏只读地看，输入框的位置换成一条「几时归档的，只能看」和 RESTORE，右栏 CHANGES 只看。
- **菜单栏**：在跑变样，等你批或答换成问号，两个以上在跑旁边写个数；通知能关。

## 设置

左边竖排十组，右边是内容，改了马上生效（Key、价格这类要点 SAVE）：

- **GENERAL**：API 请求发到哪（MOCK / REAL）、发通知、每月上限（`$` + 数字框）、这个月花了（20 格的进度条，左边写「花了 / 上限」；到 80% 琥珀、到上限红）、每个任务最多几轮、额度提醒（开关在数字框左边，关了框变灰）。三个数字框一样宽、左右对齐，单位在框外占固定的宽。
- **PROVIDERS**：每家一块：Key 框 + SAVE + REMOVE；Aliyun 多地域和业务空间 ID；Vertex 一行两个方框（GCLOUD、PROJECT ID 的状态）。
- **AGENTS**：委派给谁；PRESETS 一行一套：USE / IN USE、EDIT 展开改名字和写规范 / 实施 / 审查 / 委派，自带的改过有 RESET、自己的能 DELETE（点两下）、ADD PRESET 按左栏现在的组合起头。
- **QUOTA**：汇率；价格表 REFRESH；按家分组，一行一个模型（进、出、缓存命中、缓存写入、分档、高峰倍数），EDIT 就地改，改过的标 EDITED、能 RESET，ADD MODEL 加自己的。
- **ACCESS**：默认档、五类高危、「总是允许」能撤。**CLI**：CLI 目录，五家的色点 / 版本 / 位置（FOUND / NOT FOUND），Claude Code、Codex 的 LOGIN / RELOGIN。**LOOK**：明暗、编辑器（能打字的下拉）、App 图标 J2 / A3。**MCP**：一行一台，TEST 列出工具（只读的带锁、会删改的写出来）；编辑时有「钥匙串」一行存要保密的变量。**ARCHIVE**：见上。**KEYS**：键盘一览。

**项目设置**（右键 → 项目设置）：名字、文件夹、默认预设（有它「默认谁来干」变灰）、默认谁来干和权限、SCHEDULE（一行一个：开关、RUN NOW、EDIT、REMOVE）、FOLDERS（每行 READ / WRITE）、ENV（`NAME=value`）、MCP（`.mcp.json` 里的和设置里的放在一起：名字、出处、命令、开关、TEST）、SKILLS（名字、在哪、描述、开关；用了几次、30 天没用的琥珀色、有旧版的能 RESTORE）、COMMANDS、VERIFY（`.peck/verify.toml` 原文，SAVE 就是确认；「CLI 做完也跑」开关）、MEMORY、「总是允许」过的、ARCHIVE ALL TASKS、移出列表。

**额度与花费**（顶栏 QUOTA）：顶上三块读数（这个月 API 花的和上限、近几天 CLI 折算的、DeepSeek 余额）；按引擎叠的每天柱子（7D / 30D / 90D）；按模型和引擎的横条；每个客户端一张订阅额度卡，每个窗口一条 20 格刻度，写还剩多少（剩 25% 起琥珀、10% 起红），没读到写原因、留上次的读数；旧的调用记录在页底。

## 谁来干

左栏的 `[ AGENTS ]`：

- **预设**（最上面一行）：一个下拉，写套用着的那套（改过就加「· 改过」），没用写「不用预设」。现在用不了的变灰；最下面「管理预设」到设置 → AGENTS。
- **FLOW**：API（Peck 循环配一个 API 模型）、CLI（一个 CLI 整包干）、接力（前一个只读写规范、后一个照着做）。用不了的变灰，点了说为什么。
- **API**：按供应商分组的下拉（只列配了 Key 的，后面价格），下面思考强度。**CLI**：五家点选（没检测到变灰；Antigravity 写「直接调用」），下面是这家的模型和强度。**接力**：「写规范」「实施」两行下拉。
- **审查**（隔一条线）：OFF 或一个 API 模型 / CLI。委派在设置 → AGENTS。存着的选择现在用不了就显示成没选，发的时候也当没选。
- 在跑时不能换，头上写「在跑，跑完再换」。收起时头上一行写短的：用着预设、没改过写预设名，不然写「接力」或那一个的名字。

NEW TASK 上「WHO」下面一行一个（接力两行，审查、委派各一行），下面是没确认的 `[ VERIFY ]`（Peck 猜的验证命令：CONFIRM / EDIT / NOT NOW）。ONE SHOT 自己留着 FLOW（只有 API、CLI）。

## 输入框

- 按 Markdown 边打边渲染；↵ 发送，⇧↵ 或 ⌘↵ 换行（输入法选字的回车不算）。没有 SEND 按钮：右下角一个 ↵，提示怎么发，也能点；在跑时那里是 STOP。
- **下面一行暗字**写现在是谁，短的：用着预设、没改过写预设名；不然写「接力」或模型名，开了审查、委派各加两个字。悬停看全的（模型、强度、审查和委派是谁）；点它展开 AGENTS、闪一下。
- **再下面一行**：权限三档 PLAN / EDIT / AUTO，按需多几样选项片，最右是用量小环、这个任务累计的花费、↵。
  - **WORKTREE**：git 项目、不是 PLAN 时出现；点亮了这一次在独立工作区里做，发完自动熄。
  - **GOAL**：有确认过的验证命令、不是 PLAN 时出现（Antigravity 不出）；选一条、全部或关。和接力、审查不能一起用。
  - **用量小环**（只有 Peck 循环）：12 个像素点，亮几个是上下文用了几成，到压缩线变琥珀；点开 `[ CONTEXT ]` 看四块各多少。
- **贴图、拖图**：上面一排小图，× 去掉，发出去清掉。
- **@ 旧任务**、**斜杠命令**：打 `@` 或整句只有 `/` 加几个字时在输入框上方弹列表，↑ ↓ 选、↵ 或点击、Esc 关。不用参数的命令马上做，别的填成「/名字 」等你写参数。
- **输入框上方的条**：额度提醒（琥珀：「Claude Code 每周已用 90%，换成 Codex？」、「这次换」「以后都换」、×）；命令结果（VERIFY 绿边 / 红边、UNDO 琥珀边带确认、其余灰边）。

## 权限

默认 EDIT：

| | 改文件 | 跑命令 | 装依赖、起常驻进程 | 高危：删文件、推送和改历史、写到项目外、改系统设置、看不出会做什么的命令 |
|---|---|---|---|---|
| PLAN（只读） | 不改 | 只读沙箱里跑 | — | 弹卡片 |
| EDIT（默认） | 不问 | 不问 | 问一次（能选「这个项目总是允许」） | 弹卡片 |
| AUTO | 不问 | 不问 | 不问 | 弹卡片 |

高危卡片只有 ALLOW、DENY；不是高危的多一个 ALWAYS，点过的在设置 → ACCESS 里能撤。CLI 引擎弹同一套卡片。

## 过程

Peck 循环和 CLI 引擎同一套显示（`src/shell/AgentView.tsx`）：

- **回答**按 Markdown 显示。任务清单在过程最上面。
- **工具调用**（学 Claude Code，英文）：连着的折成一组，头上一行「Read 3 files, edited 2 files, ran 1 command · 38s」（按出现的先后：read / listed / searched for / edited / ran / fetched / searched the web / recalled memory / used N skills / ran N subagents / used N tools…），失败的组标 FAIL；点开每步一行，标题也是英文（Run pnpm test、Edit src/a.ts），改的带 Diff 入口和 +/−，跑的带 exit 码、能看输出。各引擎给的中文标题在前端翻（`englishTitle`），旧记录一样。
- **思考**不算一步、不单独占行，也不打断上下的工具调用：在想时那一组下面一行「Thinking… 3s」，想完就不显示。
- **卡片**：审批（`[ RISK ]` 高危 / `[ ALLOW? ]`）、ASK（问题 + 选项 + 自己写）；Peck 不在最前面时发通知。任务结束了卡片不能再点。
- **花费**：每次任务下面一行（进、出、缓存命中、花费；CLI 估的标「估」，算不出写「花费未知」）。
- **`[ VERIFY ]`**：每条一行（名字、耗时、命令和结果），没过的展开输出；头上写结论：都过了（绿）、没过交回去修第几次（琥珀）、停下的原因（红）。
- **合作的每一段**：每段前一行：色点、`SPEC` / `BUILD` / `REVIEW` / `FIX`、谁、状态和用时；审查后一个框「要改 · 交回去修一次」（琥珀）或「通过」（绿）。有验收标准时审查那一段下面一张逐条的清单（✓ / ✗ / ？、编号、原文、理由）。
- **委派**：主线里一步「交给子任务：…」，子任务的几步挂在这一步下面（左边一道虚线），在跑时摊开，跑完收成一行。Claude Code 自己的子代理一样。
- **recap**（每轮末尾）：「做完了 / 停下了 / 停了」和一串事实；合作、委派过的多一张按段花费的小表；最新一轮下面是下一步按钮（点了接在输入框里、不直接发）。
- **`[ MEMORY ]`**（任务收尾后）：每条一个勾，SAVE n、SKIP。**`[ SKILL ]`**（不打断任务）：名字、描述、正文或替换的 Diff、放项目 / 全局、标黄的提醒；SKIP、EDIT、SAVE。
- 其他：压缩上下文每步一行暗字；截图那一步下面一张小图；换引擎一行暗字；COPY 悬停时出现；后台命令一行名字、状态和命令。
- 任务名是第一句话去掉 Markdown 记号。v0.8 以前的旧记录照旧按步骤显示、只读。

## 右栏

页签 CHANGES / LOG / ONE SHOT / FILES / PREVIEW / TERM（⌘1–⌘6）只有像素图标，选中的带名字。那边有新东西时页签上标出来，从不自己切走正在看的。模块都能展开到宽栏。

- **CHANGES**：改了哪些文件、Diff、任务前快照，最下面「撤销整个任务」（原地确认一次）。默认看最新一次；点中栏某次记录头上的 CHANGES 换成那一次。
  - 按块：每块头那行 REJECT、ACCEPT，之后写 REJECTED / ACCEPTED。
  - 批注：点行号出一格输入，批过的行号变琥珀；顶上「n 条批注 · CLEAR · TO TASK」。
  - 独立工作区：顶上琥珀条「在独立工作区里做完了，项目文件夹还没动 · DISCARD · APPLY」；冲突时列出文件、APPLY ANYWAY / CANCEL。
- **LOG**：存快照、每一步、做完、撤销。
- **ONE SHOT**：问一句答一句，不打断任务、不锁终端、不改文件（Antigravity 不在）。回答下面一行花费，只给 COPY 和 TO TASK。
- **FILES**：只看不改。照忽略规则藏起 node_modules 这些；改过的文件和 CHANGES 一样标；md、html、svg 有 VIEW / SRC；图片在棋盘格底上；Office 这类显示 Quick Look 缩略图。预览头右边 OPEN / FINDER。
- **PREVIEW**：模块头写路径，右边每个 dev server 一个小片（名字前一颗点，在跑时点亮、点是绿的；点一下起或停）；下面地址栏（地址、GO、RELOAD、NOTE）和白底的页面。NOTE 点亮时悬停的元素描青框，点一下出一格输入；攒着的批注「n 条批注 · CLEAR · TO TASK」。
- **TERM**：开在项目根目录，不经过权限三档，不进模型上下文。模型跑任务时锁着（从发出到做完都算），输出照样能看；之前就在跑的命令接着跑。

## 样子

方案 `peck`：**点阵终端 × 深海**。深色是深海底上一层 LED 点阵孔，青 `#00E5FF` 是全屏唯一会发光的颜色；浅色是冷白底，青换成深青 `#007A94`，不发光。

- **怎么接**：根元素 `data-theme="dark"` 或 `"light"`；先引 `peck.css`（变量、字体样式类 `t-*`），再引 `bundle.css`（`pk-` 组件，写法照 `components/<组件>/preview.html`）。界面只用 `--color-*` 变量和 `pk-` 类名，不抄色值；方案里还没有的样式在 `src/app.css`。
- **颜色**：只留给意思：青在发生、绿新增和完成、琥珀等你、红删除和出错；同一时刻只有一个青色主按钮、一块模块描彩边。身份色只做 7 像素色点：Muse 紫、Grok 橙、Codex 品红、Claude Code 陶土、Antigravity 青柠、API 蓝。图表系列色跟着引擎（`--chart-*`）。
- **字**：名字和标题用缝合像素 12；说明和正文 IBM Plex Sans + 苹方；代码、路径 Departure Mono；数字、标签、按钮 Doto 900，只写英文大写（`[ CHANGES ]`、`STOP`）。
- **代码配色**（`--code-*`）：关键字青、字符串灰绿、数字沙色、类型淡紫、属性灰蓝、注释暗字斜体；不用绿红琥珀。
- **形**：没有圆角，全是像素阶梯角；模块两层，状态靠外层换色；发光只在深色、只给青色；键盘焦点是控件里一圈青点线。图标 8×8 像素格画成 16，不混别的图标集、不用 emoji。
- **尺寸**：三栏 288 / 自适应 / 336，栏间 16；顶栏高 44；按钮 34、小按钮 26、输入行 30、列表行 23、菜单行 30。
- **动效**：一格 50ms，一步一格地跳。控件状态立刻变；出现、露出 4–8 格；发出、等你、做完、撤销各有一个招牌动作，单次不超过 1 秒。减弱动态效果时只留最后的样子。
- **图标**：App 图标 J2（像素鸟），设置里能换成 A3。菜单栏模板图高 18pt，状态：空闲、在跑（三颗点轮流亮）、等你（问号）、在跑 N 个（旁边写数字）。文件在 `src/vendor/peck/marks/`。
