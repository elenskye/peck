## 布局

三栏，Phase 3 起：

```
┌────────────────────────────────────────────────────────────┐
│ 项目名                                    QUOTA      设置 │  ← 顶栏只有这三样
├──────────────┬──────────────────────────┬──────────────────┤
│ 项目和任务     │ 对话                      │ 右栏：四个页签     │
│              │                          │ CHANGES ONE SHOT │
│ 项目列表       │ 任务的提问、回答、总结      │ FILES   TERM     │
│  └ 最近几次任务 │ 折叠的步骤（点开看输出）    │                  │
│ 点进项目：     │ 停下来问你 / 高危操作卡片   │ 一次开一个，      │
│  任务列表      │                          │ 能展开到宽栏       │
│              │ ┌──────────────────────┐ │                  │
│              │ │ 一句话 谁来干 强度 权限│ │                  │
│              │ └──────────────────────┘ │                  │
└──────────────┴──────────────────────────┴──────────────────┘
```

- **窗口**：红绿灯在顶栏那一行、PECK 左边（`tauri.conf.json` 的 `trafficLightPosition`，在 Mac 上量过）；按住顶栏的空白、PECK、项目名都能拖窗口。
- **打开 App**：左栏是项目列表，每个项目带最近几次任务；还没项目时是空状态，一个「打开项目文件夹」。
- **左栏**：上面一块 PROJECTS：点项目展开它的任务列表（新的在上，第一行 NEW TASK），别的项目收成一行；再点一下项目名或「全部项目」回到项目列表。在跑的任务有标记。下面一块 LOG：正在看的这个任务的记录（存快照、每一步、做完、撤销）。
  - **右键**项目：重命名、项目设置、在访达里显示（文件夹不在了时换成「重新找文件夹」）、移出列表（点两下，第二下写明「文件夹和记录不动」）。右键任务：重命名、删除任务（点两下，第二下写「删掉，不能撤回」；在跑的不能删）。重命名就地变成输入框，回车存、Esc 不改。
  - **按住拖动**项目或（展开的项目里的）任务换顺序，拖的时候放下的位置画一条青线；没拖过的新项目、新任务排在最上面。
  - **文件夹不在了**：项目那一行换成琥珀色的感叹号和「文件夹不在了」，点进去中栏是 MISSING：FIND FOLDER（换成现在的位置，任务和快照跟过去）或 REMOVE；不能发任务。
- **项目设置**（右键 → 项目设置，占宽栏）：名字、文件夹（SHOW IN FINDER、CHANGE FOLDER）、默认谁来干、默认权限（GLOBAL 就跟全局）、这个项目「总是允许」过的（能撤）、移出列表。
- **中栏**：上面是任务内容，下面是发任务的输入框和「谁来干」。跑完的任务末尾是一段总结和验证结果。
- **右栏**：四个页签，见下面「右栏」。
- **设置**：一个面板占宽栏，左边竖排七组，每组只放现在这套东西：供应商和 Key（Key、百炼的地域、Vertex）、花费上限（每月上限和这个月花了多少）、权限（默认档、五类高危、「总是允许」的清单能撤）、CLI 检测（CLI 目录、五家引擎的色点 / 版本 / 位置、CLI 账号）、通知、外观（明暗、App 图标 J2 / A3）、开发者选项（假 Agent、API 模拟 / 真实、导出调用记录；LEGACY 一块放旧的接力清单、规划 + 实施的模型和上限，v0.8 并进新循环后删）。
- **额度与花费**（顶栏 QUOTA，占宽栏）：顶上三块读数（这个月 API 花的和花费上限的 20 格进度、近几天 CLI 估的、DeepSeek 余额）；「每天花了多少」按引擎叠起来的柱子（7D / 30D / 90D，悬停看当天明细，能切成表）；「花在哪」按模型和引擎的横条（花了多少、几次、进出 Token）；「订阅额度」每个客户端一张卡：每个窗口一条 20 格的刻度和数字，都是还剩多少（剩 25% 起琥珀、10% 起红）、近 7 天还剩的折线、多久后重置，手工记也填还剩多少，手工记一笔收在卡片底下；旧的规划 + 实施的调用记录收在页底。
- **菜单栏**：一个小图标，有任务在跑时变样（v0.7 起显示在跑的数量）；任务完成、要回答时发 macOS 通知，设置里能关。
- **明暗**：跟随系统。

## 谁来干

输入框下面三个按钮（站主 2026-11-13 定），选项片上前面一个暗的按钮名、后面是选中的：

- **FLOW**（怎么干）：API（Peck 循环配一个 API 模型）、CLI（一个 CLI 整包干）、接力（两个 CLI，先写规范再实施）、规划 + 实施（两个 API 模型），开发者选项开着时还有假 Agent。用不了的变灰、写为什么（没配 Key、没检测到）。换 FLOW 回到这种干法上次选的那个。
- **CLI**（FLOW 是 CLI、接力时出）：CLI 单选一家（Claude Code、Codex、Muse、Grok、Antigravity，只列检测到的，后面写账号和版本；Antigravity 写「直接调用」，不进 ONE SHOT 和任何自动化）；接力选一对（Muse → Grok、Grok → Muse）。
- **API**（FLOW 是 API、规划 + 实施时出）：API 按供应商分组单选一个模型（只列配了 Key 的，后面写价格）；规划 + 实施分别选规划的、实施的模型（没配 Key 的变灰）。

FLOW 是 API、CLI 时后面再跟思考强度（能开能关的多一个 OFF），然后是权限三档。ONE SHOT 用同一套按钮，FLOW 只有 API、CLI。菜单里的中文用像素字（缝合像素 12，按钮、标签里按 12 号画），右边的说明照旧用正文字。顶栏不分 CLI / API。接着在同一个任务里发一句，Peck 循环带上前面的对话，CLI 引擎续接上一次的会话。

## 权限

发任务时在「谁来干」旁边选，三档，默认 EDIT（站主 2026-11-10 定）：

| | 改文件 | 跑命令 | 装依赖、起常驻进程 | 高危：删文件、推送和改历史、写到项目外、改系统设置、看不出会做什么的命令 |
|---|---|---|---|---|
| PLAN（只读：读代码、写计划） | 不改 | 只读沙箱里跑 | — | 弹卡片 |
| EDIT（默认） | 不问 | 不问 | 问一次（能选「这个项目总是允许」） | 弹卡片 |
| AUTO | 不问 | 不问 | 不问 | 弹卡片 |

命令默认联网，只限制写到项目外（沙箱拒了再弹一张高危卡片问要不要出沙箱）。高危卡片只有 ALLOW、DENY；不是高危的多一个 ALWAYS，点过的在设置 → 权限里能撤。CLI 引擎的档位由 Gateway 映射成各家的参数，弹的卡片是同一套。

## 过程

Peck 循环和 CLI 引擎同一套显示（统一事件，`src/shell/AgentView.tsx`）：

- **回答**按 Markdown 显示，站主发的话也是；输入框边打边渲染（标题、粗体、`代码`），↵ 发送，⇧↵ 或 ⌘↵ 换行（列表里接着列表；输入法选字的回车不算）。
- **思考**折叠成「思考 · 12s」；**连续的工具调用**折叠成一行「读了 4 个文件、改了 2 个、跑了 1 条命令 · 38s」，在跑的那一步露出来；点开每一步一行：改的带 Diff 入口和 +/−，跑的带退出码，点开看输出，太长的能打开完整日志。
- **卡片**：审批（`[ RISK ]` 高危 / `[ ALLOW? ]`）、ASK（问题 + 选项 + 自己写）。Peck 不在最前面时发通知（和「做完发通知」一起开关）。任务清单在过程最上面，做到哪一步写在头上。
- **花费**：每次任务下面一行（进、出、缓存命中、花费；CLI 估的标「估」，算不出写「花费未知」，不当 0）；输入框旁是这个任务累计；QUOTA 页写这个月 Peck 循环花了多少。到了设置里的每月上限，下一次请求前停下，任务写明原因。
- 任务的名字是第一句话去掉 Markdown 记号，通知正文也是。
- 任务结束了（包括 App 中途退出过、引擎没起来）卡片就不能再点，在跑的工具收成「停了」。
- 旧的记录（v0.4 的 CLI、接力、规划 + 实施）照旧按步骤显示。

## 右栏

顶上一条页签：CHANGES / ONE SHOT / FILES / TERM，一次开一个。切走以后页签上说那边有新东西（改了几个文件、答完了、命令在跑或跑完、终端锁着），从不自己切走正在看的页签。每个模块都能展开到宽栏（中栏和右栏合起来）；展开时任务停下来等你，宽栏顶上一条提示，点 BACK 收回。模块之间只靠「带上」和「跳过去」连，不开新窗口。

- **CHANGES（改动）**：这个任务改了哪些文件，点文件看 Diff；任务前快照；最下面「撤销整个任务」（原地确认一次）。一个任务里发过好几次时，默认看最新一次；中栏每次记录的头上有一个 CHANGES，点了右栏和左栏的 LOG 就换成那一次（快照那一行写着是任务几号），再发一次回到最新。读不出 Diff 时写明原因（比如项目文件夹不在了）。
- **ONE SHOT（边干活边问）**：问一句答一句，不打断任务、不锁终端。
  - 谁来答：左下 FLOW、CLI / API 按钮（只有 API 模型和 CLI，Antigravity 除外），默认跟中栏「谁来干」选的，换了就记住；支持的模型旁边选思考强度。
  - 能读整个项目，不改文件：Peck 循环只给读的工具，CLI 按 PLAN 档跑。过程和中栏一样折叠成一行。
  - 回答下面一行花费（API 算进花费上限，CLI 标「估」）；回答只给 COPY 和 TO TASK（放进中栏输入框）。切去别的页签再回来，问到一半的和答完的都还在。
- **FILES（看文件）**：只看不改。照忽略规则藏起 node_modules 这些并写一句藏了几个；这个任务改过的文件标法和 CHANGES 一样；预览带行号，改过的行左边一条绿，删掉的文件预览删之前的样子。
- **TERM（你的终端）**：开在项目根目录，不经过权限三档，不进模型上下文；Agent 跑的命令在中栏步骤里看。每条命令跑完写退出码和用时，失败那条能带上输出去 ONE SHOT。
  - 模型在跑任务时终端锁着（站主 2026-11-10 定）：从发出到做完，等你批、等你答、撤销的时候都算，PLAN 档也锁。输入行和页签各一把锁；输出照样能看、能带去 ONE SHOT。
  - 发任务前就在跑的命令接着跑，STOP 一直能点；它要是改了项目里的文件，算进这次改动。
  - 做完解锁。之后在终端改的文件不算进这个任务，撤销只动任务改过的文件，确认里写清。

## 样子

方案 `peck` 0.1.0（站主 2026-11-10 批，Design System「[Peck](https://claude.ai/artifact/KpUihg5AHn6cw1ggNTx6s1)」）：**点阵终端 × 深海**。深色是深海底上一层 LED 点阵孔，青 `#00E5FF` 是全屏唯一会发光的颜色；浅色是冷白底，青换成深青 `#007A94`，没有发光。不像 VSCode：不用一层层灰面板 + 满屏等宽字。

- **怎么接**：根元素写 `data-theme="dark"` 或 `"light"`（`src/lib/theme.ts`，跟随系统）；先引 `src/vendor/peck/peck.css`（变量、字体样式类 `t-*`、两个字体），再引 `bundle.css`（组件类名都以 `pk-` 开头，写法照 `components/<组件>/preview.html`）。界面只用 `--color-*` 这些变量和 `pk-` 类名，不抄色值。
- **颜色**：34 个角色，深浅两套。颜色只留给意思：青在发生、绿新增和完成、琥珀等你、红删除和出错；同一时刻只有一个青色主按钮、只有一块模块描彩边。图表的系列色跟着引擎走（`--chart-*`）：浅色就是身份色，深色用同一色相深一级（大面积填色太亮），叠放顺序固定为 Antigravity、Peck 循环、Grok、Muse、Claude Code、Codex（相邻两色色弱也分得开，深浅两套跑过校验）；图上的字一律用文字色。身份色只做 7 像素的色点，五家 CLI 各一色：Muse 紫、Grok 橙、Codex 品红（`#E879F9` / `#A21CAF`）、Claude Code 陶土（`#F0997A` / `#B4532A`）、Antigravity 青柠（`#A3E635` / `#4D7C0F`）；API（Peck 循环、规划 + 实施）蓝。后三色是站主 2026-11-13 要的，先写在 `src/app.css`，APCA 色点门槛 45 深浅都过，本地改方案时并进 tokens。改色要过 APCA。
- **字**：名字和标题用缝合像素 12（12、18、24 号）；说明和正文用 IBM Plex Sans + 苹方（12.5 号）；代码、路径用 Departure Mono 11（字号不小于 12 的唯一例外）；数字、标签、按钮用 Doto 900，只写英文大写（`[ CHANGES ]`、`SEND`）；混进来的中文（菜单项、选项片、右键菜单）落到缝合像素 12，按 12 号画（`src/app.css` 的 `Peck Pixel CJK *`，站主 2026-11-13 要的，本地改方案时并进 tokens）。
- **形**：没有圆角，全是像素阶梯角（模块 2 级 × 3px，控件 2 级 × 2px）；模块两层，状态靠外层换色；发光只在深色、只给青色；键盘焦点是控件里面一圈青点线。图标 8×8 像素格画成 16，不混别的图标集、不用 emoji。
- **尺寸**：三栏 288 / 自适应 / 336，栏间 16；顶栏高 44；按钮 34、小按钮 26、输入行 30、列表行 23、菜单行 30；间距只用 2、4、6、8、10、12、14、16、18、22、28、30。
- **动效**：一格 50ms，一步一格地跳，时长都是整格。控件状态立刻变；出现、露出、溶掉 4–8 格（calm）；发出、等你、做完、撤销这几个时刻各有一个招牌动作，单次不超过 1 秒；在跑、等待能循环。减弱动态效果时只留最后的样子。
- **图标**：App 图标 J2（像素鸟，深海渐变底板占 7/8），每个尺寸用对应的底稿（16、32 是重画的小鸟，不从 1024 缩）；设置里能换成现在的图标润色版 A3。菜单栏模板图高 18pt，14 格的鸟，在菜单栏里一格 1.5pt（鸟 15×13.5pt，和系统图标差不多大；方案里写的一格 1pt 在刘海屏的菜单栏里偏小，站主 2026-11-11 说要大一点），四个状态：空闲、在跑（三颗点轮流亮）、等你（问号）、在跑 N 个（v0.7 起）。文件在 `src/vendor/peck/marks/`。
