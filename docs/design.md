## 默认取舍

- **先保留功能、再收界面**：入口一个不少，旧组件能删就删。
- **说明文字能不写就不写，必须写就写短**（站主 2026-11-24 定，优先级最高）：不加解释「这是什么、会怎样」的句子、提示行、ⓘ；状态用图标、数字、颜色说。非写不可的（确认、错误、空状态）只留一句，弹层和卡片里也一样。以前收进 ⓘ 的旧说明先留着，改到那一处时顺手删。设置的分组名只写英文。
- 看不准的视觉细节照 `src/vendor/peck/DESIGN.md`；没写到的取沉静的那一边。

## 布局

- **顶栏**只有项目名、QUOTA、设置。红绿灯在顶栏那一行、PECK 左边；按住顶栏空白、PECK、项目名都能拖窗口。明暗跟随系统。
- **三栏**：左栏 NOW、PROJECTS、AGENTS；中栏是对话和输入框；右栏五个页签，一次开一个。设置、项目设置、QUOTA 和展开的右栏模块占宽栏（中栏 + 右栏），CLOSE 或 Esc 收回。
- **设置、项目设置是大号页**：模块里面整块放大 7/6 倍（像素名字字 12→14，和 PROJECTS 项目名一样大），从这里弹出的菜单、ⓘ 跟着放大。
- **弹层**（下拉、菜单、ⓘ、右键菜单、@ 和 / 列表）：一律用 `src/ui.tsx` 的 `<Float>`。想往哪边弹那边放不下就翻到另一边，两边都不够就压矮在里面滚；左右夹在窗口里。
- **对话的位置**：第一次进一个任务停在最新一轮的开头（最后一条 YOU 顶到上面）；回到看过的任务回到上次的位置（退出重开也记得）；离开后多了新的一轮、或在这里发了下一句，去新的那一轮。
- **全部项目页**（没选项目时）：中栏一块 `[ PROJECTS ]`，列全部项目，每个带最近 5 次任务（标题、状态和时间），多的写「还有 n 个」；头上右边 OPEN FOLDER；有等你的、在跑的，上面出 `[ NOW ]`。这时左栏一整块都是 AGENTS（一直展开，没有收起的三角）。点一个项目或任务就进去。
- **`[ NOW ]`**：跨项目的「待你处理、在跑」，没有、或 PROJECTS 收起时不出现。一行一个任务，顺序：等你批或答（琥珀问号）、停下了没看（红叉）、做完了没看（绿勾）、在跑（闪烁的点）；最多 8 行。打开过或在眼前做完的算看过。
- **PROJECTS**（选了项目以后的左栏）：项目名用像素字 14px（往上提 2px 和文件夹图标对齐）；选中的项目列全部任务（新的在上，第一行 NEW TASK），别的项目只带最近一次。头上：文件夹图标打开新项目，右边放大图标回全部项目页，最右是收起的三角；不写项目个数。
  - **定时任务的钟**（头上，有定时任务才出现；全部项目页的头上也有）：钟 + 个数，有错过的多一颗点。点开一行一个（名字、下一次或「错过了」），再点展开：到点发的那句话、项目、什么时候、下一次、谁来干和权限、在哪跑、上一次怎么样；错过的有「去点卡片」，最右 REMOVE（点两下）。设、改时间和内容都在对话里跟模型说。
  - 右键项目：重命名、项目设置、在访达里显示（文件夹不在了换成「重新找文件夹」）、归档全部任务、移出列表；右键任务：重命名、归档、删除任务（在跑的不能归档、不能删）。归档全部、移出和删除都点两下，第二下写后果；重命名就地变输入框。全部项目页里一样。
  - 拖动换顺序，放下的位置一条青线。
  - 文件夹不在了：那一行琥珀感叹号和「文件夹不在了」，中栏是 MISSING：FIND FOLDER 或 REMOVE。
- PROJECTS、AGENTS 都能收起（模块头最右的小三角），收起的只剩模块头和一行要紧的（当前项目 / 现在是谁），另一块占满；记在设置里。
- **归档**：任务收起来不在左栏列，记录、快照都留着。设置 → ARCHIVE 按项目分组列出，每行 OPEN / RESTORE / DELETE；OPEN 在中栏只读地看，输入框的位置换成一条「几时归档的，只能看」和 RESTORE。
- **菜单栏**：在跑变样，等你批或答换成问号，两个以上在跑旁边写个数；通知默认开，能关。

## 设置

左边竖排十组，右边是内容，改了马上生效（Key、价格这类要点 SAVE）。

**统一排法**（v1.1.6，设置、项目设置、小窗都照这个；样式在 `app.css` 的 `.set-scope`）：

- 一行：左边名字和一行状态，右边控件。**每行一样高**；名字、状态都不换行，放不下就省略。
- 右边的主控件（输入框、下拉、能打字的下拉、进度条）**一样宽**、右边对齐，分段至少这么宽；控件一样高；单位写在框里右边（`轮`、`%`、`USD`）。
- 小按钮一样宽。每行都有的按钮放最右边，有时才有的（RESET、UPDATE、CLEAR）放它左边，几行的按钮就对齐。
- 一行放不下的做成**一块两行**：头一行和普通行一样（名字、状态、开关），下面一行是固定的格子，几块的格子对齐（没有的那格空着）。窗口窄时格子换成两行两列，按钮多的列表（归档、MCP、价格表）每行变成两行、按钮在下面——都是整组一起变，不是自动换行。
- 一组的按钮（READ KEYS、RECHECK、CHECK ALL、ADD SERVER、ADD MODEL）放在组头右边。
- 要编辑一串东西（项目记忆）、看一个东西的全部（插件）用**小窗**：盖住整个窗口，点外面、Esc、CLOSE 都关；里面的菜单、改字的框先收自己的 Esc。

各组：

- **GENERAL**：API 请求发到哪（MOCK / REAL）、发通知、每月上限（框里写 USD）、这个月花了（名字下面写「花了 / 上限」，右边一格和输入框一样大的 20 格进度；到 80% 琥珀、到上限红）、每个任务最多几轮（默认 40）、ONE SHOT 最多几轮（12）、额度提醒（开关在数字框左边，关了框变灰）。
- **PROVIDERS**：两组。API KEYS（组头 READ KEYS）每家一块：头一行名字和状态（SAVED / NO KEY / NOT READ），下面一行 Key 框 + SAVE + REMOVE；Aliyun 头一行多一个地域（BEIJING / SINGAPORE，点了就存）；最后一块是 Vertex AI：头一行 Location 框和状态（先说缺的：NO GCLOUD、NO PROJECT ID，都有是 SAVED），下面一行 Project ID + SAVE（和 Location 一起存）+ REMOVE（清掉 Project ID）。TOOL KEYS：Tavily（联网搜索的备用）、Mathpix App ID、App Key（两样都填了 Peck Loop 才有 `ocr_pdf`），一样的块。
- **MEMORY**：一个项目一行：名字，下面「几条 · 路径」（移出列表的项目有记忆才列，排在最后、写「不在列表里」），右边 EDIT 开这个项目的记忆小窗。小窗：头上项目名和路径；一条一块，字照原样换行，下面谁提的和时间、DELETE（点两下）、EDIT（就地变多行的框，⌘↵ 存、Esc 取消）；最下面一个多行的框 + ADD 自己记一条。项目设置里的 MEMORY 是一行「这个项目的记忆」+ EDIT，开同一个小窗。
- **AGENTS**：MAIN 一块（主角色：下拉只列 API 模型 + 思考强度）；SUBAGENTS 五块，头一行名字、一句做什么、开关，下面一行四格：模型（空着写「跟主角色」）、思考强度、最多几轮（24，member 40）、同时几个（3，member 2；auditor 没有，那格空着）。思考强度按模型记，这里调的和 AGENTS 面板里的是同一档；关了的整块变暗。
- **QUOTA**：汇率（框里写 CNY / USD）；价格表（组头那一行 ADD MODEL、REFRESH）；按家分组，一行一个模型（进、出、缓存命中、缓存写入、分档、高峰倍数，太长省略、悬停看全），EDIT 在最右、就地改，改过的标 EDITED、左边多一个 RESET，自己加的能 DELETE。
- **ACCESS**：默认档、五类高危、「总是允许」能撤。**CLI**：ENGINES（组头 RECHECK）：CLI 目录一块，四家的色点 / 版本 / 位置（FOUND / NOT FOUND）；LOGIN（组头 CHECK ALL）：Claude Code、Codex 的 LOGIN / RELOGIN、CHECK。**LOOK**：明暗、编辑器（能打字的下拉）、App 图标 J2 / A3。
- **PLUGINS**：BUILT-IN、LIBRARY 两组卡片，两栏（窗口窄时一栏）；每张只有图标、名字、两行简介。图标按名字算出来的 5×5 像素（左右对称），插件青色、单独的 Skill 淡紫。点开小窗：图标、名字、版本、BUILT-IN / LIBRARY / SKILL、全部说明；库里的多一行「每个项目都装」；PROJECTS 列左栏的全部项目，自带的每个项目一个开关，库里的写装着哪一版，INSTALL / UPDATE / REMOVE（点两下）；CONTENTS 是它带的 SKILL、COMMAND（怎么打、参数、做什么）、TOOL、HOOK（什么时候、问哪一句、Peck 跑什么）、MCP。MCP SERVERS（组头 ADD SERVER）一行一台，TEST 列出工具（只读的带锁、会删改的写出来）；编辑时有「钥匙串」一块存要保密的变量。
- **ARCHIVE**：见上。**KEYS**：键盘一览。

**项目设置**（右键 → 项目设置）：名字、文件夹、默认谁来干和权限、FOLDERS（每行 READ / WRITE）、ENV（`NAME=value`）、PLUGINS（和设置里一样的卡片：这个项目里关着、没装的暗一些，库里有新版的名字后面多一个青色的版本号；点开同一个小窗，PROJECTS 只有这个项目）、SKILLS（项目自己的和插件带进来的：名字、在哪、哪个插件的、描述、开关；用了几次、30 天没用的琥珀色、有旧版的能 RESTORE）、MCP（`.mcp.json` 里的和设置里的放在一起：名字、出处、命令、开关、TEST）、MEMORY（一行 + EDIT 开小窗）、「总是允许」过的、ARCHIVE ALL TASKS、移出列表。

**额度与花费**（顶栏 QUOTA）：顶上三块读数（这个月 API 花的和上限、近几天 CLI 折算的、DeepSeek 余额）；按引擎叠的每天柱子（7D / 30D / 90D）；按模型和引擎的横条；每个客户端一张订阅额度卡，每个窗口一条 20 格刻度，写还剩多少（剩 25% 起琥珀、10% 起红），没读到写原因、留上次的读数。

## 谁来干

左栏的 `[ AGENTS ]`：

- **FLOW**：CLI（一个 CLI 整包干，Peck 只当外壳）、PLOOP（Peck Loop：一个 API 模型当主角色，能派子代理）。用不了的变灰，点了说为什么。没有 API 单干。
- **CLI**：四家点选（没检测到变灰），下面是这家的模型和强度。**PLOOP**：「主角色」一个下拉（按供应商分组，只列配了 Key 的，后面价格），下面它的思考强度；子代理在设置 → AGENTS。主角色没选过或现在用不了，显示并存下第一个能用的。
- CLI 之间交接换引擎接着发一句，或 `/review`（用现在选的那一个；PLOOP 是主角色，它还能派 auditor）。
- **头上的 ⓘ**：五类子代理各做什么；worker、member 只改划给它的文件，不重叠的同时跑、重叠的排队，进度在任务板上；在设置 → AGENTS 配模型、强度、轮数、同时几个，没单独选模型的跟主角色。
- 在跑时不能换，头上写「在跑，跑完再换」。收起时头上一行写短的：「PLOOP · 主角色名」或那个 CLI 的名字。

NEW TASK 上「WHO」下面：PLOOP 一行「主角色 · 名字」（它怎么干）、一行「子代理 · explorer、searcher…」（开着的几类，一句怎么派、在哪配）；CLI 一行。再下面是这个项目错过的定时任务的 `[ MISSED ]` 卡片。ONE SHOT 自己留着 FLOW（API、CLI）。

## 输入框

- 按 Markdown 边打边渲染；↵ 发送，⇧↵ 或 ⌘↵ 换行（输入法选字的回车不算）。没有 SEND 按钮：右下角一个 ↵，提示怎么发，也能点；在跑时那里是 STOP。
- **下面一行暗字**写现在是谁，短的：「PLOOP · 主角色名」或 CLI 的名字。悬停看全的（主角色、思考强度、「子代理在设置 → AGENTS」）；点它展开 AGENTS、闪一下。
- **再下面一行**：权限三档 PLAN / EDIT / AUTO，按需多几样选项片，最右是用量小环、这个任务累计的花费、↵。
  - **WORKTREE**：git 项目、不是 PLAN 时出现；点亮了这一次在独立工作区里做，发完自动熄。
  - **用量小环**：12 个像素点，亮几个是上下文用了几成。Peck Loop 到压缩线变琥珀，点开 `[ CONTEXT ]` 看四块各多少、压缩线在哪。CLI 报了「用了 / 窗口」才出（v1.1.7）：点开写「上下文 X / Y · 压缩由 Claude Code 自己管」，不画压缩线，Muse 说快满了才变琥珀；两次回合之间显示上次记下的数，CLI 自己压过一次以后点变暗、写「这个数是压之前的」，等下一句的用量。
- **贴图、拖图**：上面一排小图，× 去掉，发出去清掉。
- **`+`**（v1.1.8）：最左边一片，点开「文件」（多选）、「文件夹」（一次一个）；挑的在上面排成小片（图标 + 名字 + ×），最多 10 个。
- **@ 旧任务**、**斜杠命令**：打 `@` 或整句只有 `/` 加几个字时在输入框上方弹列表，↑ ↓ 选、↵ 或点击、Esc 关。不用参数的命令马上做，别的填成「/名字 」等你写参数。
- **输入框上方的条**：额度提醒（琥珀：「Claude Code 每周已用 90%，换成 Codex？」、「这次换」「以后都换」、×）；命令结果（灰边）。`/undo` 是发一句话给模型，它用任务快照放回去，动之前弹高危卡片。
- **`/compact [重点]`**（v1.1.7）：压这个任务的对话，落成一次新记录。PLOOP：落盘、清旧输出、叫一次模型写交接摘要（三步都做，重点写进摘要的要求）；CLI：转给它自己压（Codex、Muse、Grok 不收重点，写一行说明）。任务在跑时提示「跑完再压」。

## 权限

默认 EDIT：

| | 改文件 | 跑命令 | 装依赖、起常驻进程 | 高危：删文件、推送和改历史、写到项目外、改系统设置、看不出会做什么的命令 |
|---|---|---|---|---|
| PLAN（只读） | 不改 | 只读沙箱里跑 | — | 弹卡片 |
| EDIT（默认） | 不问 | 不问 | 问一次（能选「这个项目总是允许」） | 弹卡片 |
| AUTO | 不问 | 不问 | 不问 | 弹卡片 |

高危卡片只有 ALLOW、DENY；不是高危的多一个 ALWAYS，点过的在设置 → ACCESS 里能撤。CLI 引擎弹同一套卡片。
- **信任文件夹**（v1.1.8）：CLI 没信任项目文件夹、站主也没在 Peck 里批过时，任务开头一张 `[ TRUST ]` 卡片「让 X 信任这个项目文件夹？」，NOT NOW / TRUST，点了才起 CLI。TRUST 记在这个项目上（项目设置里一个开关能关），留一行「信任了这个文件夹 · X」；NOT NOW 这次打开 Peck 期间不再问。

## 过程

Peck Loop 和 CLI 引擎同一套显示（`src/shell/AgentView.tsx`）：

- **回答**按 Markdown 显示。任务清单在过程最上面（四家 CLI 的清单一样显示，Claude Code 的 `TodoWrite` / `TaskCreate` 也转过来）。
- **任务板**（PLOOP 派了 worker、member 时代替任务清单）：头一行「任务板」和做完几项（收起时写「n 个在跑」「n 个等你批」）；上面是主角色自己那几步（勾选框），下面一项一行：状态（排队暗字、在跑青、等你批琥珀、做完绿、没做完红、停了暗字）、做什么、`WORKER 2` / `MEMBER 1`、用时，下一行暗字写它划的文件。点一项展开它自己的几步（member 派的 explorer 再挂在那一步下面），排着队的写「还在排队，没开始」。
- **工具调用**（学 Claude Code，英文）：连着的折成一组，头上一行「Read 3 files, edited 2 files, ran 1 command · 38s」（按出现的先后：read / listed / searched for / edited / ran / fetched / searched the web / recalled memory / used N skills / ran N subagents / used N tools…），失败的组标 FAIL；点开每步一行，标题也是英文（Run pnpm test、Edit src/a.ts），改的带 Diff 入口和 +/−，跑的带 exit 码、能看输出。各引擎给的中文标题在前端翻（`englishTitle`）。
- **思考**不算一步、不单独占行，也不打断上下的工具调用：在想时那一组下面一行「Thinking… 3s」，想完就不显示。
- 英文只到工具调用的组和 Thinking 为止；卡片、recap、提醒行这些细的信息用中文。
- **卡片**：审批（`[ RISK ]` 高危 / `[ ALLOW? ]`）、ASK（问题 + 选项 + 自己写）；Peck 不在最前面时发通知。任务结束了卡片不能再点。
- **花费**：每次任务下面一行（进、出、缓存命中、搜了几次、花费；CLI 估的标「估」，算不出写「花费未知」）。
- **搜网页**：供应商自己搜的、Peck 的 `web_search` 一个样，一次一步「Search the web: …」，输出里列来源。
- **子代理**：主线里一步「Spawn explorer: …」，子代理的几步挂在这一步下面（左边一道虚线，头上「explorer · 模型名」）；没碰过时在跑摊开、跑完收起，点过就按点的来；派的那一步等它做完才算完。一批报告交回来时不单独显示。Claude Code 自己的子代理一样。
- **Hook**：项目里配的脚本拦下了、出错了、有输出时，在当时那一处一行提示「Hook 调工具前 · 命令第一行（出处）：拦下了：…」（拦下、出错的琥珀，有输出的暗字）；静默成功的不显示。第一次跑一条命令前弹审批卡片（标题写时刻和命令）。
- **原地打转**：同一步第 3 次一样时一行琥珀提示「read_file 同样的参数、同样的结果已经第 3 次了…」；第 5 次要它收尾，还要调工具就停下，recap 写原因。
- **recap**（每轮末尾）：「做完了 / 停下了 / 停了」和一串事实；装着 Git Plan 的项目多一行收尾提交的结果（绿勾「Git Plan 提交了 3f9c2ab：v1.1.0: …（2 个文件，没有 push）」，没提交的是琥珀感叹号加原因）；派过子代理的多一张按主线、子代理分的花费小表；最新一轮下面是下一步按钮（点了接在输入框里、不直接发）。
- **独立工作区**（recap 下面）：琥珀条「在独立工作区里做完了，项目文件夹还没动 · DISCARD · APPLY」；冲突时列出文件、APPLY ANYWAY / CANCEL。
- **`[ MISSED ]`**（错过的定时任务）：名字和时间规则、原定几点和为什么错过、到点要发的那句话；RUN NOW、SKIP。每次开新任务的出在这个项目的新任务页，接在某个对话里跑的出在那个对话末尾；刚打开 App 时有错过的就跳到第一个那里。
- **`[ MEMORY ]`**（任务收尾后）：每条一个勾，SAVE n、SKIP。**`[ SKILL ]`**（不打断任务）：名字、描述、正文或替换的 Diff、写进项目的哪、标黄的提醒；SKIP、EDIT、SAVE。
- **`/compact` 那一次**：不画 YOU，一行暗字「COMPACT 压缩上下文 · 重点：…」；下面的过程照常（压缩的几步、花费），结果写「上下文压缩好了」或「X 压缩了上下文」。
- **读网页**（v1.1.7）：一步「Fetch 主机/路径」，和搜网页算在一组（「Searched the web 2 times, fetched 1 page」）；点开头上一行最后的网址（点了用系统浏览器打开），下面是给模型的那份原文（标题、类型和大小、截断落盘的路径都在头几行）。跳到别的网站、本机地址、不支持的类型是普通的失败一步，不弹卡片。
- 其他：压缩上下文每步一行暗字（交接摘要能点开看原文；CLI 自己压的写「CLI 自己压」）；截图那一步下面一张小图；换引擎一行暗字；COPY 悬停时出现；后台命令一行名字、状态和命令。
- 任务名是第一句话去掉 Markdown 记号。引擎没起来、一条过程都没有的，过程写「这次没有记下过程」，下面照样有状态和结果那一句。

## 右栏

页签 FILES / LOG / ONE SHOT / PREVIEW / TERM（⌘1–⌘5）只有像素图标，选中的带名字。那边有新东西时页签上标出来，从不自己切走正在看的。模块都能展开到宽栏。没有审改动、撤销的页签：要看改了什么点对话里的文件名（在 FILES 里打开），要反悔跟模型说。

- **FILES**：只看不改。照项目的 `.gitignore` 藏起 node_modules 这些；有藏着的，头上多一片 **ALL**（v1.1.8）：点亮了藏着的也列出来、字变暗，藏着的文件夹点开才读那一层（一层最多 500 个）；开关记在这台机器上。这次任务改过的文件标 NEW / DEL / + −，加的行左边一条绿，页签上写改了几个；md、html、svg 有 VIEW / SRC；图片在棋盘格底上；Office 这类显示 Quick Look 缩略图。预览头右边 OPEN / FINDER。默认看最新一次；点中栏某次记录头上的 LOG 换成那一次。
- **LOG**：PLOOP 的任务最上面一块成员名单（MAIN 和开着的几类子代理：模型名，思考强度 · 轮数 · 同时几个；派之前就定了，一个任务里不变）；下面时间线：存快照、每一步、派了谁（模型 · 做什么）、它做完 / 被停下了 / 没做完、做完、撤销。
- **ONE SHOT**：问一句答一句，不打断任务、不锁终端、不改文件。回答下面一行花费，只给 COPY 和 TO TASK。
- **PREVIEW**：模块头写路径，右边每个留着在跑的 dev server 一个小片（名字前一颗绿点；点一下停，要再起跟模型说）；下面地址栏（地址、GO、RELOAD、NOTE）和白底的页面。NOTE 点亮时悬停的元素描青框，点一下出一格输入；攒着的批注「n 条批注 · CLEAR · TO TASK」。
- **TERM**：开在项目根目录，不经过权限三档，不进模型上下文。模型跑任务时锁着（从发出到做完都算），输出照样能看；之前就在跑的命令接着跑。

## 样子

方案 `peck`：**点阵终端 × 深海**。深色是深海底上一层 LED 点阵孔，青 `#00E5FF` 是全屏唯一会发光的颜色；浅色是冷白底，青换成深青 `#007A94`，不发光。

- **怎么接**：根元素 `data-theme="dark"` 或 `"light"`；先引 `peck.css`（变量、字体样式类 `t-*`），再引 `bundle.css`（`pk-` 组件，写法照 `components/<组件>/preview.html`）。界面只用 `--color-*` 变量和 `pk-` 类名，不抄色值；方案里还没有的样式在 `src/app.css`。
- **颜色**：只留给意思：青在发生、绿新增和完成、琥珀等你、红删除和出错；同一时刻只有一个青色主按钮、一块模块描彩边。身份色只做 7 像素色点：Muse 紫、Grok 橙、Codex 品红、Claude Code 陶土、API 蓝。图表系列色跟着引擎（`--chart-*`）。
- **字**：名字和标题用缝合像素 12；说明和正文 IBM Plex Sans + 苹方；代码、路径 Departure Mono；数字、标签、按钮 Doto 900，只写英文大写（`[ FILES ]`、`STOP`）。
- **代码配色**（`--code-*`）：关键字青、字符串灰绿、数字沙色、类型淡紫、属性灰蓝、注释暗字斜体；不用绿红琥珀。
- **形**：没有圆角，全是像素阶梯角；模块两层，状态靠外层换色；发光只在深色、只给青色；键盘焦点是控件里一圈青点线。图标 8×8 像素格画成 16，不混别的图标集、不用 emoji。
- **尺寸**：三栏 288 / 自适应 / 336，栏间 16；顶栏高 44；按钮 34、小按钮 26、输入行 30、列表行 23、菜单行 30。
- **动效**：一格 50ms，一步一格地跳。控件状态立刻变；出现、露出 4–8 格；发出、等你、做完、撤销各有一个招牌动作，单次不超过 1 秒。减弱动态效果时只留最后的样子。
- **图标**：App 图标 J2（像素鸟），设置里能换成 A3。菜单栏模板图高 18pt，状态：空闲、在跑（三颗点轮流亮）、等你（问号）、在跑 N 个（旁边写数字）。文件在 `src/vendor/peck/marks/`。
